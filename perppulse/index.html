§ 01 · What it does

// intelligence.
not noise.

python · fastapi · claude · sqlite
01/

Multi-source collection

Pulls from protocol-native blogs, governance forums, docs changelogs, X feeds, GitHub releases, and RSS every day.

  • 20 protocols, 60+ source URLs
  • Medium, Substack, native blogs
  • GitHub release notes
  • DefiLlama volume data
02/

LLM classification + ranking

Claude Haiku classifies each item by category and scores it 1–10 on impact. Falls back to heuristic scoring without an API key.

  • Categories: product, governance, partnership, content
  • Impact score 1–10 per item
  • Deduplication across sources
  • Age labels (today / 2d / 1w)
03/

Dashboard + daily brief

FastAPI + Jinja2 dashboard with five tabs. Open manually after the scheduled morning run.

  • Today — ranked feed
  • Campaigns & Launches
  • Threat Board
  • 30-Day Calendar
  • Coverage — source health
04/

Scheduled daily run

Runs at 08:00 IST via macOS launchd (or on server via APScheduler). One command to trigger manually.

  • launchd plist included
  • APScheduler for server deploys
  • Logs to data/run_logs/
05/

Open source

Full source on GitHub. MIT license. Self-host locally or deploy to Fly.io with the included Dockerfile and fly.toml.

  • Python 3.12+, editable install
  • SQLite — zero config DB
  • Docker + Fly.io ready
  • 15 tests, fully green
06/

Why I built it

Working in perp DEX marketing means knowing every move every competitor makes. Manual tab-checking is how signals get missed. This replaces that.

  • Built for perp-DEX marketing leads
  • No SaaS subscriptions
  • Runs overnight, read in the morning
